# Azure Cosmos DB

Azure Cosmos DBは、Microsoftが提供するグローバル分散型マルチモデルデータベースサービスです。

## 主な特徴

- **グローバル分散**: 世界中の複数のリージョンにデータを自動的にレプリケートし、低レイテンシーでアクセス可能
- **マルチモデル**: SQL API、MongoDB API、Cassandra API、Gremlin API、Table APIなど複数のAPIをサポート
- **スケーラビリティ**: スループットとストレージを個別にスケーリング可能
- **高可用性**: 99.999%のSLAを提供
- **NoSQLデータベース**: スキーマレスなデータモデルをサポート

## ユースケース

- グローバルWebアプリケーション
- IoTデータ管理
- リアルタイム分析
- パーソナライゼーション
- ゲーム開発

## Vector Search

最近追加されたVector Search機能により、Cosmos DBは埋め込みベクトルを効率的に検索できるようになりました。これにより、以下のようなシナリオが可能になります：

- セマンティック検索
- レコメンデーションエンジン
- 類似画像検索
- RAG（Retrieval Augmented Generation）

Vector Searchは、埋め込みベクトル間の類似性をコサイン類似度やユークリッド距離などのメトリックを使用して計算します。これは、従来のキーワードベースの検索よりも意味的な関連性に基づいて検索することができます。
